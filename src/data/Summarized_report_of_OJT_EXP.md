# Systems Administration & IT Support Experience

## Role Overview
Managed end-to-end workstation provisioning, hardware refurbishment, network diagnostics, and enterprise software licensing across multi-laboratory academic computing environments and administrative offices. Combined rapid disk-imaging deployment architectures with component-level hardware salvaging and network administration to standardize cross-generational workstations and minimize operational downtime.

## Core Technical Skills Acquired

* **System Imaging & Deployment Architecture:** Designed and maintained universal and generation-specific master disk images, executing batch workstation provisioning via both local disk cloning and networked image deployment.
* **Enterprise Software Provisioning & License Remediation:** Audited workstation software environments, resolved licensing and activation conflicts, and executed parallel offline installations using multi-drive flash media to bypass network bandwidth bottlenecks.
* **Hardware Diagnostics & Component-Level Salvaging:** Diagnosed failing desktop hardware, harvested viable components from decommissioned units to assemble functional 10th- through 12th-Generation workstations, and refurbished interactive help-desk kiosks.
* **Network Troubleshooting & IP Auditing:** Traced physical and logical network loopback anomalies, audited IP configurations, and patched wireless access point connectivity across administrative environments.
* **Identity & Access Management (IAM) & Data Administration:** Managed network authentication databases to provision user Wi-Fi access and maintained centralized administrative records under strict backend scalability constraints.
* **Audiovisual & Peripheral Infrastructure:** Executed quality assurance diagnostics on classroom multimedia displays, deployed dedicated HDMI cabling, and maintained workstation peripherals.

## Operational Impact

* **Rapid Fleet Standardization:** Built and deployed generation-specific disk images across 10th- to 12th-Generation desktop architectures, drastically reducing setup time for specialized technical curricula.
* **Zero-Cost Hardware Recovery:** Repurposed salvaged internal components into fully operational deployment swaps, extending hardware lifecycles and eliminating immediate procurement bottlenecks.
* **High-Volume Network Onboarding:** Processed and registered massive backlogs of user credentials into the campus Wi-Fi authentication portal through structured batch encoding despite non-scalable legacy backend infrastructure.
